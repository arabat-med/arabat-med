# Visuel du profil

[`header.svg`](header.svg) est une bannière vectorielle locale créée pour ce profil : bleu nuit, ardoise et bleu clair. Elle est statique, sans script, animation, police distante ni ressource externe. Le nom et le positionnement sont aussi disponibles dans le Markdown.

Les projets sont présentés par leur contexte, les contributions, les technologies, les livrables et les liens vers le code. Aucune capture de projet n’est intégrée au profil.
